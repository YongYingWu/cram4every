# cram4everything
一、试卷注册表 assets/index.json
首页列表靠它驱动，每套试卷一条记录：
[
  {
    "id": "2026-fujian-xingce",
    // 试卷唯一标识（必填）
    // 要求：全库唯一、建议用英文/数字/连字符，不要中文和空格
    // 用途：①浏览器本地保存作答记录的 key（quiz_<id>）
    //       ②刷题模式里区分题目来自哪套试卷

    "title": "2026年福建省公务员录用考试《行测》真题（考生回忆版--估分版）",
    // 试卷标题（必填）
    // 显示位置：首页卡片标题、做题页顶部标题、浏览器标签页标题

    "subtitle": "星光公考 · 含答案与详细解析",
    // 副标题（可选）
    // 显示在首页卡片标题下方，可写来源、特点等；不填则不显示该行

    "total": 120,
    // 题目总数（必填）
    // 用于：首页卡片显示"共 N 题"、首页"已答 x/N"进度、刷题模式进度校验
    // 必须与 file 里题目数组的实际长度一致

    "scorePerQuestion": 1,
    // 每题分值（可选，默认按 1 分处理）
    // 用于交卷后的得分计算：得分 = 答对题数 × scorePerQuestion

    "file": "assets/papers/2026-fujian-xingce.json",
    // 题库文件路径（必填）
    // 相对于 index.html 所在目录的相对路径

    "updatedAt": "2026-03-14"
    // 更新日期（可选）
    // 显示在首页卡片"更新于 xxxx-xx-xx"，格式建议 YYYY-MM-DD；不填则不显示
  }
]

二、题库文件 assets/papers/<id>.json
顶层是一个数组，每个元素是一道题，按 num 顺序排列：
[
  {
    "num": 1,
    // 题号（必填，number 类型）
    // 从 1 开始、建议连续；同一试卷内唯一
    // 用于：题目卡片编号、答题卡格子、作答记录的 key

    "section": "第一部分 政治理论",
    // 所属模块（必填，string）
    // 相同 section 的题会被归到同一个模块标题下
    // 答题卡侧栏按它分组，交卷后的分模块统计也按它计算
    // 命名建议保持"第x部分 xxx"格式，侧栏分组标签会自动去掉"第x部分"前缀

    "abstract": "",
    // 共用材料/背景资料（可选，没有就填空字符串 ""）
    // 仅资料分析等"一则材料带多题"的题目有值，同一则材料的每道题都带一份
    // 渲染为题干上方的灰底材料框，HTML 格式（可含 <br>、<img>、<table>）

    "stem": "习近平总书记强调，学习好贯彻好党的二十届四中全会精神……下列表述正确的是：",
    // 题干正文（必填，HTML 片段）
    // 不要带题号前缀（"1."由页面自动渲染）
    // 支持的 HTML：换行用 <br>；图片 <img src="assets/img/xxx.png">；
    //              表格 <table class="qtable"><tr><td>…</td></tr></table>

    "options": [
      "把捍卫经济安全摆在首位，加强重点领域国家安全能力建设……",
      "坚定不移推动高质量发展……",
      "坚定不移扩大高水平对外开放……",
      "加强普惠性、基础性、兜底性民生建设……"
    ],
    // 选项数组（必填，目前按 4 个处理，顺序即 A→B→C→D）
    // 内容不含字母前缀（A/B/C/D 圆圈由页面自动渲染）
    // HTML 格式，规则同 stem；图形选项就直接放 <img> 标签
    // 渲染、选中、判分时按下标对应：options[0]=A、options[1]=B…

    "answer": "D",
    // 正确答案（必填，单个大写字母 A/B/C/D）
    // 模拟考交卷判分和刷题模式即答即判都以它为准
    // 必须与 options 的下标对应：answer="D" 即 options[3] 正确

    "analysis": "Ⅰ找考点：本题为重大会议会议内容常识……故本题选D。【2026-联考/福建-001】"
    // 解析文本（必填，可为空字符串但不建议，HTML 格式）
    // 显示位置：模拟考交卷后每题下方、刷题模式作答后
    // 页面上方会自动加一行"正确答案：X"，所以 analysis 里不用再写答案本身
  }
]
